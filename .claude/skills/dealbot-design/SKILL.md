# dealbot 디자인 시스템: "가격이 곧 포스터"

할인 정보 계정의 카드는 영화 포스터처럼 읽혀야 한다. 그림은 게임의 키아트가, 헤드라인은 **할인 숫자**가 맡는다. 나머지(스토어, 정가, 종료 시각, 한국어, 평가)는 포스터 하단의 크레딧처럼 조용히 받친다. 대담함은 한 곳(할인 숫자)에만 쓰고 주변은 절제한다.

## 토큰

| 역할 | 값 | 쓰는 곳 |
|---|---|---|
| 바탕 | `#000` (진짜 검정) | 모든 슬라이드의 기본 바탕, 패널 |
| 글자 | `#f4f4ef` | 본문, 제목 |
| 보조 글자 | `rgba(244,244,239,.62)` | 정가, 스토어명, 출처 |
| 신호색 | `#ffd60a` | **돈을 아끼는 정보만**: 더 싼 스토어("최저"), 강조된 종료 시각, 결산 바탕, 수요일 인디 바탕, 마지막 장 |
| 게임 색 | 키아트에서 추출 (`palette.accent`) | 할인율 블록 하나 |
| 경고 | `#ff6b5a` | "한국 계정 미제공" |

글꼴은 두 가지만: **Pretendard**(한글·본문, 400~900) + **Anton**(숫자: 할인율, 순위, 큰 통계). 크기 단계: 22 / 28 / 31 / 46 / 60 / 84 / 138px (1080×1350 기준).

## 레이아웃

- 여백은 좌우 48px. 상단 크레딧 줄(브랜드 왼쪽, "43호  10.19–10.25" 오른쪽)은 모든 슬라이드 공통.
- 요일별 배치: 월 report(숫자판), 화 cinema(와이드 키아트 + 공식 로고), 수 grid(노란 바탕 4칸), 목 duo(2단), 금·토 poster(세로 키아트 + 패널), 일 recap(노란 장부). 새 포맷은 이 중 하나를 쓰거나, 같은 토큰으로 새 배치를 만든다.
- 순위 숫자(01, 02 …)는 실제로 순서가 있는 목록에만 쓴다.

## 인스타 UI 안전 영역

인스타는 게시물 위에 UI를 항상 띄운다. 글자·가격·로고는 아래 영역에 두지 않는다 (1080px 기준).

| 형식 | 피할 곳 |
|---|---|
| 피드 캐러셀 4:5 | 오른쪽 위 장수 표시(1/10): 크레딧 줄은 왼쪽에 모은다. 영상 표지의 오른쪽 아래 음소거 버튼. 프로필 격자는 3:4로 좌우 34px씩 잘림. 슬라이드 번호는 인스타가 보여 주므로 넣지 않는다 |
| 스토리 9:16 | 위 250px(진행 막대·프로필), 아래 300px(답장 칸) |
| 릴스 9:16 | 위 250px, 아래 520px(아이디·캡션·음악), y 900 아래 오른쪽 160px(좋아요·댓글·공유) |

확인: `python scripts/check_safe_zones.py feed|story|reel 입력 출력` 으로 덮이는 곳을 빨갛게 칠해 본다.

## 하지 말 것 (생성형 디자인의 흔한 티)

- 제목 위의 영문 대문자 라벨(eyebrow). 포맷 이름은 한국어 헤드라인이 말한다.
- 가운뎃점으로 이어 붙인 메타 문자열(`A · B · C`). 줄을 나누거나 아이콘 정보 줄로 쪼갠다.
- 헤드라인에서 한 단어만 색을 바꾸는 강조.
- 링크·안내 문구 끝의 화살표(`→`).
- 모든 요소가 하나씩 올라오는 페이드업. 슬라이드당 움직임은 **한 번**: 패널이 올라오고 할인율·가격 숫자가 바뀌는 순간. 표지만 키아트 띠가 흐른다.
- 장식용 반짝임, 그라데이션 띠, 둥근 카드에 같은 그림자.
- 확인되지 않은 판정("역대 최저가")을 기본 표시. `DEALBOT_SHOW_VERDICT` 로만 켠다.

## 점검표 (렌더링 후 확인)

1. 1080px 너비 PNG를 폰 크기(약 400px)로 줄여 봤을 때 할인율, 가격, 제목이 읽히는가. 정보 줄 글자는 31px 이상인가.
2. 키아트에 박힌 로고가 패널에 반쯤 잘려 지저분하지 않은가(하단 페이드가 받쳐 주는가).
3. 같은 정보가 두 번 나오지 않는가(가격 블록 ↔ 정보 줄 ↔ 목록 보조 줄).
4. 신호색이 돈을 아끼는 정보 외에 쓰이지 않았는가.
5. 글자가 넘치거나 겹치지 않는가(긴 제목은 2줄에서 자른다).
6. `scripts/check_safe_zones.py` 로 피드·스토리·릴스 프레임을 겹쳐 봤을 때 빨간 영역에 글자가 없는가.
7. 마지막으로 "액세서리 하나 빼기": 지금 빼도 정보가 줄지 않는 장식이 있으면 뺀다.
