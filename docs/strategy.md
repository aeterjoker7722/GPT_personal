# 게임 할인 인스타그램 계정 운영 전략

> 경쟁 조사 원문: [competitor_research.md](competitor_research.md)
> 자동화 도구: 저장소 루트의 `dealbot/` ([README](../README.md))

## 1. 시장 판단 (조사 결과 반영)

- **한국어 PC 게임 할인 전문 인스타그램 계정이 검색에 노출될 만큼 자리 잡은 사례가 없다.** 수요는 퀘이사존, 아카라이브, ITCM, 유튜브, 텔레그램이 채우고 있다.
- 영어권 대형 딜 큐레이터(Wario64, GG.deals)도 인스타그램은 거의 비워 두고 X에 집중한다.
- 현지어 계정이 커질 수 있다는 근거: 터키어 @steam_tr 약 22.4만 명, 영어 @free_game_alert 약 4.5만 명.
- "free steam" 계열 인스타그램 계정에는 계정 판매나 사기형 계정이 섞여 있다. 그래서 **신뢰가 곧 차별점**이 된다.

결론: 이 분야는 경쟁 계정을 이기는 싸움이 아니다. **커뮤니티와 유튜브에 흩어진 수요를 인스타그램 포맷으로 가져오는 것**이 핵심이다.

## 2. 포지셔닝

**"사도 되는지 알려주는 한국어 게임 할인 계정"**

| 차별점 | 구현 |
|---|---|
| 지금 사도 되나 판정 | 🟢 역대 최저가 / 🟡 최저가 근접 / 🔴 더 기다리기 (`dealbot` 판정 배지) |
| 한국 사용자 기준 | 원화 가격, 한국어 지원(음성/자막/미지원) 배지, 스토브와 다이렉트게임즈 포함 |
| 스토어 간 비교 | 같은 게임이 다른 스토어에서 더 싸면 그쪽을 노출 |
| 신뢰 | 공식 스토어와 공인 키셀러 링크만 소개. 평가 75% 이상, 할인 50% 이상만 선별 |
| 정시성 | 에픽 무료게임은 목요일 자정(KST)에 바로 업로드 |

## 3. 콘텐츠 캘린더

| 요일 | 피드 | 스토리 |
|---|---|---|
| 월 | 주간 할인 TOP 캐러셀 (`python -m dealbot run`) | 판정 배지 설명 |
| 수 | 시리즈: 5천 원 이하 명작 / 한국어 지원 할인작 / 역대 최저가 갱신 | 투표 "이 가격이면 산다?" |
| 목 자정 | (스토리) 에픽 무료게임 정시 알림 | 링크 스티커 |
| 금 | 릴스 15초 "이번 주말 놓치면 안 되는 3개" | 주말 세일 마감 알림 |
| 대형 세일 1주 전 | "세일 대기 리스트" 캐러셀 (저장, 공유 유도) | 카운트다운 스티커 |

하이라이트: `지금 무료` / `역대 최저가` / `한국어 지원` / `판정 기준`

### 영상 활용 (`python -m dealbot run --motion --reel`)

- **캐러셀 첫 장은 MP4**: 피드에서 자동재생되어 스크롤을 멈추게 합니다. 나머지 장은 PNG로 둬도 됩니다.
- **릴스는 주 1~2회**: 트레일러 위 TOP 3를 15초 안팎으로. 음악은 인스타 앱 음원 라이브러리에서 추가합니다(트렌딩 음원은 노출에 유리).
- **스토리에는 9:16 영상이나 메인 카드 MP4**를 링크 스티커와 함께 올립니다.
- 시안별 역할 예시: 주간 TOP은 poster(릴스와 같은 언어), 최저가 갱신은 ticker(차트), 무료게임은 receipt("0원 영수증").
  시안 비교: [template_design.md](template_design.md)

## 4. 성장 장치

- **댓글 위시리스트**: "기다리는 게임 댓글로 남기면 할인할 때 알려드림". DM 자동화 도구로 키워드 응답.
- **저장 유도**: 마지막 장 CTA를 "놓치기 전에 저장"으로 고정. 이 분야는 저장 수와 공유 수가 성장 지표다.
- **반응 좋은 포맷**(조사 기반 추론): "무료 N개 + 최대 할인율" 묶음, 마감 카운트다운, 정가 강조("8만 원 게임 무료"), 평점 근거, 역대 최저가.
- **교차 유입**: 퀘이사존과 아카라이브에 정리 글을 올리면서 출처로 계정을 표기. 원본 핫딜을 무단으로 재가공하지는 않는다.

## 5. 수익화와 법적 체크

- 제휴: Humble, Fanatical, GreenManGaming 같은 해외 공인 셀러는 제휴 프로그램이 있다. 국내 셀러는 개별 문의.
- 제휴 링크가 들어가면 **[광고] 표기가 필수**다(공정위 추천·보증 심사지침). `--affiliate` 옵션을 쓰면 캡션과 마지막 장에 표기가 자동으로 들어간다.
- G2A, Kinguin 같은 그레이마켓은 다루지 않는다. 다룬다면 공인 셀러와 반드시 구분해 표시한다.
- 이미지는 스토어 공식 이미지(헤더 캡슐)만 쓰고, 가격은 "게시 시점 기준"이라고 표기한다.
- 장기 해자: 프로필 링크를 자체 비교 웹페이지로 키워 검색 유입과 제휴 수익을 확보한다.

## 6. 로드맵

1. **0~4주**: 핸들과 브랜드 확정. GitHub Actions로 가격 기록 쌓기 시작. 주 2~3회 캐러셀, 에픽 정시 스토리.
2. **1~3개월**: ITAD 키를 연결해 판정 배지 상시 운영. 반응 좋은 시리즈 집중. 커뮤니티 교차 게시.
3. **3개월 이후**: 위시리스트 DM 자동화, 자체 비교 웹페이지, 제휴 수익화.

## 7. 직접 확인할 것 (조사로 확인하지 못한 부분)

- 인스타그램 앱에서 #스팀할인 #스팀무료게임 #에픽무료게임 해시태그 상위 계정
- 다이렉트게임즈, 스토브, 에픽게임즈 코리아, 퀘이사존 공식 계정의 유무와 팔로워 수
- 원하는 핸들의 사용 가능 여부
