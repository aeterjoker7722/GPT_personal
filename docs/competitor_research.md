# 게임 할인·무료게임 인스타그램 계정 경쟁 분석

- 조사일: 2026-10-24
- 대상: 스팀, GOG, 에픽, 스토브, 다이렉트게임즈 등 키셀러의 할인과 무료 배포를 알리는 인스타그램 계정 (한국 시장 중심, 비교용 해외 계정 포함)
- 방법: 웹 검색 결과 스니펫, 공개 웹페이지, 커뮤니티 글. 인스타그램 페이지는 직접 열리지 않았습니다(HTTP 429). HypeAuditor와 ITCM도 403으로 막혔습니다. 그래서 **팔로워 수는 모두 검색엔진에 색인된 프로필 스니펫 기준**이고, 정확한 색인 시점은 대부분 알 수 없습니다. 아래 "확인 시점"은 이 조사에서 스니펫을 본 날짜(2026-10-24)입니다.
- 표기 규칙: 확인하지 못한 항목은 "미확인"으로 적었습니다. 출처가 없는 해석에는 **[추론]**을 붙였습니다.

## 0. 요약 결론

1. **한국어로 PC 키셀러 할인과 무료게임만 다루는 인스타그램 계정은 검색으로 하나도 확인하지 못했습니다.** 한국어 검색, `site:instagram.com` 검색, 해시태그형 키워드 검색 10회 이상에서 같은 결과였습니다. 한국 게이밍 인스타그램 상위 97개 계정 목록(Scrumball, 2026년 10월)에도 이런 계정은 없었습니다.
2. 한국의 할인 정보 수요는 인스타그램 밖에서 채워지고 있습니다. 커뮤니티 게시판(퀘이사존, 아카라이브 핫딜, ITCM, 디시 스팀 갤러리), 유튜브 "스팀 할인 게임 추천" 영상, 텔레그램 알림 채널, 스팀 그룹, 가격 추적 사이트가 그 역할을 합니다.
3. 영어권에서도 대형 딜 큐레이터는 인스타그램이 아니라 X에 있습니다. Wario64는 X 약 160만 명, 인스타그램 1,687명(게시물 0개)입니다. GG.deals는 X 약 3.06만 명, 인스타그램 266명(게시물 0개)입니다.
4. 인스타그램에서 확인된 무료게임 특화 계정 중 가장 큰 영어권 계정은 Free Game Alert(@free_game_alert, 약 4.5만 명)입니다. 영어권이 아닌 계정 중에서는 터키어 계정 SteamTürk(@steam_tr, 약 22.4만 명)가 가장 컸습니다.
5. 인스타그램의 "free steam" 계열 계정에는 계정 판매, 계정 공유, "온라인 활성화" 계정이 많이 섞여 있습니다. 이런 계정은 신뢰도를 떨어뜨리는 요인이고, 반대로 새 계정이 신뢰로 차별화할 여지가 됩니다.

## 3. 공통 패턴

1. **무료게임이 주력이고 할인 큐레이션은 적음.** 인스타그램에서 확인된 계정 대부분이 "free games / giveaways"를 소개 문구에 내세웁니다 (@free_game_alert, @epic_free_games, @freesteamgametw). 출처는 2-1, 2-2 표의 각 프로필입니다.
2. **멀티 플랫폼 통합.** 스팀과 에픽을 기본으로 GOG, Ubisoft, EA를 함께 다룹니다 (@freesteamgametw 소개 문구).
3. **카드형 정보 구성.** 제목, 장르, 평점, SteamDB 평점, 링크, 기한을 한 장에 담습니다 (Free Game Alert의 TikTok·X 게시물 구성).
4. **같은 브랜드로 여러 채널 운영.** Free Game Alert는 5개 채널에서, RaidLine은 텔레그램, 디스코드, X, 인스타그램에서 같은 이름을 씁니다.
5. **대형 딜 브랜드는 인스타그램을 사실상 비워 둠.** Wario64와 GG.deals는 게시물이 0개입니다. 링크를 클릭하기 어려운 인스타그램의 구조 때문으로 보입니다 **[추론]**.
