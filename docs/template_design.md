v1에서 바뀐 점:
- **영화 포스터 문법**: 상단 크레딧 라인(브랜드 · 포맷 · 호수 · 기간), 하단 **빌링 블록**(세로로 늘린 좁은 글자로 판매가, 정가, 한국어, 평가, 개발사, 출시 연도, 할인 종료 시각)
- **회전하는 씰**: 역대 최저가 "최저", 최저가 근접 "근접", 마감 임박 "D-2 / 14H", 무료 "FREE". 판정이 없는 게임에는 씰을 달지 않습니다.
- **브랜드 고정색은 시그널 옐로 하나**: 씰, 상단 포맷명, 마지막 장. 할인 블록은 게임마다 키아트에서 뽑은 색이라 피드가 다채로우면서도 계정 정체성이 유지됩니다.
- **세로 배치**: 검은 크레딧 바, 키아트, 패널 순서. 키아트 아래쪽에 박힌 로고가 패널에 반쯤 잘리지 않습니다.
- **표지**: 키아트 다섯 장을 세로 띠로 엇갈려 흘리고, 포맷별 헤드라인과 핵심 숫자(최대 할인, TOP 5 할인액, 가장 빠른 마감)를 크게
- **모션**: 띠가 위아래로 엇갈려 흐르고, 패널이 올라오고, 할인율이 튀어나오며 빛이 한 번 지나가고, 씰이 돌며 찍힘
- **릴스**: 트레일러 위에 **스팀 공식 로고**(있는 게임만)와 같은 2단 패널. 금요일 릴스는 마감 임박 게임으로 구성
- **계정 안내(`post guide`)**: 판정 기준과 편성표. 고정 게시물용

## 초기 시안 4종 (비교용)

목표는 **템플릿 티가 나지 않는 디자인**입니다. 그래서 4개 시안 모두 다음 규칙을 따릅니다.

- 이모지, 둥근 알약 모양 칩, 네온 글로우, 의미 없는 그라데이션은 쓰지 않습니다.
- 대신 실제 인쇄물이나 앱에서 가져온 시각 언어를 씁니다(잡지, 영수증, 증권 앱, 영화 포스터).
- 종이와 필름 그레인을 깔아 디지털로 매끈한 면을 없앱니다.
- 서체는 역할별로 2~3종을 섞습니다(명조와 고딕, 고정폭, 압축 숫자).
- 게임 이미지는 스토어 공식 키아트를 쓰고, 포스터 시안은 키아트에서 뽑은 색을 그대로 씁니다.

샘플 이미지와 영상은 `docs/samples/<theme>/`에 있습니다. 가격 이력과 판정은 **디자인 확인용 가상 데이터**이며, 카드에 "샘플 데이터"라고 표시됩니다.

## 시안별 콘셉트

### 1. editorial: "이번 주, 사도 되는 게임 13"
- 종이색 배경에 Noto Serif KR 900 헤드라인, IBM Plex Mono로 정리한 데이터, 빨간색 하나만 포인트
- 표지는 잡지 목차처럼, 메인 카드는 기사처럼 구성(fig. 캡션, 정가/할인/지금 3단 표, 판정 문장, 가격 이력 스파크라인)
- 모션: 이미지가 위에서 아래로 열리고, 정가에 취소선이 그어지고, 가격이 정가에서 할인가로 내려감
- 어울리는 계정 톤: 신뢰, 큐레이션, "고르는 눈"

### 2. receipt: "할인 영수증"
- 코발트 배경 위에 감열지 영수증(톱니 모양 아래 가장자리, 하프톤 흑백 인쇄 이미지, 바코드)
- 판정을 **고무도장**으로 찍음: 역대최저(빨강), 최저근접(주황), 대기권장(파랑), 추적중(회색)
- 표지에 "할인 합계 -₩158,440"을 넣어 **아끼는 금액**을 앞세움. 무료 게임은 "0원 영수증"
- 모션: 영수증이 프린터처럼 출력되고, 결제 금액이 내려가고, 도장이 쾅 찍힘
- 어울리는 계정 톤: 위트, 저장과 공유가 잘 되는 밈형 포맷

### 3. ticker: "게임을 종목처럼"
- 국내 증권 앱 문법을 따름: 하락은 파랑, 큰 현재가, 6개월 계단형 가격 차트, 매수 의견(적극 매수/매수/관망)
- 표지는 "게임 할인 지수 ▼79%"와 종목 리스트. 무료 게임은 "무상 배정 종목"
- **가격 추적 데이터가 가장 잘 드러나는 시안**입니다. 기록이 쌓이면 차트가 실제 시세가 됩니다(기록이 없으면 정가에서 현재가로 가는 2점 차트).
- 모션: 차트 선이 그려지고, 현재가가 카운트다운되고, 현재 지점에 맥박 링이 뜸
- 어울리는 계정 톤: 2030 남성, 커뮤니티 친화, "가격 덕후"

### 4. poster: "키아트가 주인공"
- 스팀 세로 키아트(600×900 @2x)를 꽉 채우고, 아래 색 띠는 **게임마다 키아트에서 뽑은 색**
- 압축 숫자 서체 Anton으로 −80%를 크게. 표지는 키아트 모자이크
- 모션: 켄 번스 줌, 색 띠가 올라오고, 할인율이 튀어나옴
- 어울리는 계정 톤: 피드 그리드가 가장 화려함. 릴스와 같은 디자인 언어

### 릴스 (9:16, poster 언어)
- 인트로: TOP 3 키아트 → 게임마다 **스팀 공식 트레일러 영상 위에** 할인율, 가격, 판정 → 아웃트로(저장 유도)
- 상단에는 스토리처럼 진행 막대가 있고, 인스타 UI에 가려지는 영역(위 220px, 아래 340px, 오른쪽 130px)은 피해서 배치
- 트레일러는 소리 없이 넣습니다. 음악은 인스타그램 앱의 음원 라이브러리에서 추가하세요. 저작권 문제가 없고, 노출에도 유리합니다.

## 어떻게 움직이나 (모션 파이프라인)

1. 템플릿은 평범한 HTML/CSS 애니메이션입니다. 브라우저로 `carousel.html`을 열면 그대로 재생됩니다.
2. 렌더러가 페이지의 `window.__seek(t)`로 모든 애니메이션과 숫자 카운터를 t초에 고정하고, 프레임마다 스크린샷을 찍어 ffmpeg로 인코딩합니다. 실시간 녹화가 아니라서 프레임이 끊기지 않습니다.
3. 정지 이미지는 애니메이션이 모두 끝난 6초 시점에서 찍습니다.
4. 릴스는 투명 배경으로 캡처한 오버레이를 트레일러 영상 위에 ffmpeg로 합성합니다.
5. GIF는 미리보기와 문서용입니다. 인스타그램에는 MP4를 올리세요. 캐러셀 안에 영상 슬라이드와 이미지 슬라이드를 섞을 수 있습니다.

## 사용법

```bash
python -m dealbot run --theme poster                  # 정지 이미지
python -m dealbot run --theme receipt --motion        # 표지와 메인 카드는 MP4 도
python -m dealbot run --theme all --motion all --gif  # 4개 시안 전부, 모든 장 MP4 + GIF
python -m dealbot run --reel                          # 트레일러 릴스
python -m dealbot sample --theme all                  # 네트워크 없이 샘플 데이터로
```

기본 테마는 `DEALBOT_THEME`, 브랜드명은 `DEALBOT_BRAND`, 핸들은 `DEALBOT_HANDLE`로 정합니다.

## 커스터마이즈 포인트

- 각 템플릿 맨 위 `:root`의 색과 서체 변수만 바꿔도 전체에 반영됩니다.
- receipt의 배경색(`--bg`)은 계정 시그니처 색으로 바꾸는 것을 추천합니다.
- 판정 문구는 각 템플릿 상단의 `verdict_text`, `stamp_text`, `opinion` 딕셔너리에 있습니다.

## 운영 팁

- **한 시안으로 통일**하는 것이 피드 그리드에 좋습니다. 다만 시리즈별로 시안을 고정하는 방법도 좋습니다(예: 월요일 주간 TOP은 poster, 수요일 최저가 갱신은 ticker, 목요일 무료게임은 receipt "0원 영수증").
- 첫 장을 영상으로 올리면 피드에서 자동재생되어 멈춰 보게 만드는 효과가 큽니다. `--motion`으로 만든 `slide_01.mp4`를 캐러셀 첫 장으로 쓰세요.
- 트레일러와 키아트는 퍼블리셔의 홍보용 자료지만, 권리는 각 퍼블리셔에 있습니다. 출처(스토어 링크)를 남기고, 권리자가 요청하면 내리세요.
